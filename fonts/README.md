# fonts/

Drop .ttf/.otf files here for a 1:1 look with eDEX-UI:

- `united_sans_medium.ttf` — UI font (headers, clock, keyboard),
- `fira_mono.ttf` — terminal font.

Conversion from the eDEX-UI repository (.woff2 files): use `woff2_decompress`.
Without these files ng-term falls back to the closest system fonts.
